# Invasie-inator

Pixel-invaders in "Vroeger was alles beter"-stijl met een LEDJOCKEY-tintje.

**Speel / installeer:** https://jimmyhonderd.github.io/invasie-inator/

## Installeren op Android

1. Open de link hierboven in Chrome.
2. Tik op ⋮ (rechtsboven) → **App installeren**.
3. De app staat daarna tussen je apps, start schermvullend en werkt offline.

## Besturing

- Touch: vinger slepen = schip bewegen, tikken of vasthouden = vuren. Geen knoppen.
- Pc: pijltjes = bewegen, spatie = vuren, P = pauze.

## Wat erin zit

- Drie rijen invaders (groen, cyaan, magenta) die versnellen naarmate er minder over zijn en terugschieten.
- Groene bunkers die stuk voor stuk wegschieten; de middelste draagt VWAB. Paarse UFO voor bonuspunten.
- Oplopende levels, highscore op het toestel, schermvullend op telefoon en tablet.
